# Urlaubsplaner

Tool für die **unverbindliche Vorplanung** von Urlaub und anderen Abwesenheiten im Team. Es löst die jährliche Excel-Urlaubsliste ab. Die offiziellen Anträge werden weiterhin im ESS gestellt.

**Status:** Spezifikation (Entwurf) und klickbarer Prototyp mit fiktiven Daten.

| Dokument | Inhalt |
|---|---|
| [docs/LASTENHEFT.md](docs/LASTENHEFT.md) | Anforderungen, Berechnungsregeln, Datenschutz, Architekturvorschlag, offene Punkte |
| [BERECHTIGUNGEN.md](BERECHTIGUNGEN.md) | Rollen- und Rechtematrix |
| [prototyp/Urlaubsplaner-Prototyp_v0.2.html](prototyp/Urlaubsplaner-Prototyp_v0.2.html) | Klickbarer Prototyp: eine HTML-Datei, im Browser öffnen, ohne Server und ohne Netzaufrufe. Beispieldaten oder testweise eingelesene Excel-Urlaubsliste (nur im Browserfenster, nichts wird gespeichert) |

Hinweis: Sobald das Tool von Kolleg*innen mit echten Daten genutzt wird, gehört der Quellcode in ein Azure-DevOps-Repository.
